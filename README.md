# Satya extension download

**Download:** https://github.com/coolcoolercoolestkid/satya/raw/extension-download/satya-extension.zip

Satya Chrome extension, built from commit 6732aee. Its links point at the live web app (https://satya-web-blush.vercel.app).

**Install (about 1 minute)**
1. Download `satya-extension.zip` below and unzip it.
2. Open `chrome://extensions` and turn on **Developer mode** (top right).
3. Click **Load unpacked** and pick the unzipped `satya-extension` folder.
4. Pin Satya from the puzzle-piece menu and click it on any site to open the side panel.

Live sites: Aletheia https://satya-aletheia.vercel.app · Satya web app https://satya-web-blush.vercel.app
